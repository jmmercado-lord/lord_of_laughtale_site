# Lord of Laughtale — sitio para GitHub Pages

Sitio estático listo para publicar en GitHub Pages.

## Archivos
- `index.html` — página principal.
- `style.css` — diseño responsive.
- `script.js` — animaciones y año del footer.
- `assets/logo.png` — logo proporcionado.
- `assets/banner.jpg` — banner proporcionado.
- `.nojekyll` — evita que GitHub Pages intente procesar el sitio con Jekyll.

## Publicación rápida

1. Sube todos estos archivos al repositorio `lord_of_laughtale_site`.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda.
6. Espera unos minutos y abre la URL que GitHub muestre en Pages.
